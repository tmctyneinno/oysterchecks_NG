# OysterChecks v2.0

GRC and assurance platform.

| Folder | Contents |
|---|---|
| [`frontend/`](frontend/) | Nuxt 4 application, currently packaged as a static demo with hardcoded data. See [frontend/README.md](frontend/README.md). |
| [`backend/`](backend/) | Backend service. Empty for now. |

## Getting started

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
npm run generate   # static site in frontend/.output/public
```
